# uSloplist
Anti-AI ruleset for uBlacklist. Tired of uncanny "photos", stolen muddled "art", or unnatural AI-generated "music"? uSloplist aims to catch all kinds of slop, bringing back the good 'ol internet.
 
## Q&A

1. Which websites does it block?
- Sites which host a large amount of AI-generated images, especially those from companies which invest in AI (e.g., Adobe).
2. Does it block political content?
- Mostly not. Political sites are less likely to be blocked, in order to prevent censorship and bias. The political websites intended to be blocked must be completely AI-generated "news" sites, whose images show up on search results.
